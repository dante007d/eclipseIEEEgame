# Server & Backend

This folder contains the server-side code, game networking, database connections, and business logic.

### Structure
- `config/` - Environment variables, port configurations, database connections.
- `controllers/` - Route and socket controllers handling incoming game events or HTTP calls.
- `models/` - Game state models, user profiles, or DB schemas.
- `routes/` - API endpoints and route declarations.
- `src/` - Server entry point and core game-server logic.
